# AWS Student Community Day 2026 — SR University

React + Vite website with a consistent dark violet theme and the supplied AWS SBG SRU logo.

## Run locally
```bash
npm install
npm run dev
```

## Build for Vercel
```bash
npm run build
```
Vercel settings: Framework **Vite**, Build Command `npm run build`, Output Directory `dist`.

## Before publishing
Replace the `#` placeholders in `src/App.jsx` in the `LINKS` object with the official Google Form and community events URLs:
- `studentIndividual`
- `studentTeam`
- `otherIndividual`
- `otherTeam`
- `sponsorForm`
- `communityEvents`

Update the date when confirmed. Replace the speaker and sponsor placeholders with approved photos, names, titles, and organisations. The schedule is a proposed draft and should be confirmed by the event team.
